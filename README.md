# Welcome to Reactjs Quest05
***

## Task
In this project, we will build a multi-page application using React Router to navigate between different pages.
We will implement basic routing in ex00 and nested routing in ex01.

## Description
We will be creating a React app with the following pages:

Part 1: Simple Routing (ex00)
Home (/)

Users (/users)

About (/about)

Part 2: Nested Routing (ex01)
Home (/)

Users (/users)

Topics (/topics)

Nested Pages:

/topics/components

/topics/props-v-state

## Installation
Clone the repository and install dependencies:

# Clone the repository
$> git clone git@git.us.qwasar.io:reactjs-quest05_180410_wzmyj4/reactjs-quest05.git

# Navigate to the project directory
$> cd reactjs-quest05

# Install dependencies
$> npm install

## Usage
Start the development server on port 8080:
$> npm start

Modify package.json to set the port to 8080:
"start": "PORT=8080 react-scripts start"
Once started, open http://localhost:8080 in your browser.

./my_project argument1 argument2
